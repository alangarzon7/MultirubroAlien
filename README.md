# 🛸 Multirubro Alien 2.0 - Plataforma Web Oficial

Plataforma web completa y catálogo interactivo para **Multirubro Alien 2.0**. Abierto las 24 horas.

---

## 👽 Características Principales

1. **Diseño Visual Galáctico & Neón**:
   - Estética espacial con fondo interactivo de estrellas y estrellas fugaces en Canvas.
   - Cartel luminoso Neón "24 HORAS ABIERTO" activo.
   - Saludos dinámicos en tiempo real ("¡Buen día terrícola! / Saludos Terrícola 👽").
   - 100% responsivo para celulares y computadoras.

2. **Catálogo Interactivo**:
   - Buscador de productos en tiempo real con limpieza rápida.
   - Barra deslizante de categorías (Promos, Café y Merienda, Helados, Snacks, Bebidas, Cannabis & Grow, Golosinas, etc.).
   - Grid de productos con imágenes, badges, precios en ARS formateados, selectores de cantidad y estados de stock.

3. **Promociones del Día**:
   - Título configurable desde el Panel de Administrador.
   - Banners y tarjetas de combos intergalácticos con adición directa al carrito.

4. **Carrito de Compras & Checkout WhatsApp**:
   - Drawer lateral fluido con sonido espacial láser opcional.
   - Selector de modalidad: 🛵 **Envío a Domicilio** (con cálculo dinámico de envío y envío gratis) vs 🏬 **Retiro en Local** (gratis).
   - Cuadro informativo de Transferencia con botón **"Copiar Alias"** en 1 clic y modal con **Código QR** para pago con apps bancarias o Mercado Pago.
   - Generación automática del mensaje estructurado de WhatsApp listo para enviar con 1 clic.

5. **Panel de Administración (Modo Admin)**:
   - Protegido por PIN (por defecto: `alien2026`).
   - Agregar, editar, eliminar productos y alternar stock ("Disponible / Stock Agotado").
   - Crear y gestionar categorías.
   - Modificar precios de envío, alias de transferencia, número de contacto, horarios y dirección.
   - Exportación de base de datos JSON para sincronizar en la rama `main` de GitHub.

---

## 🚀 Despliegue en GitHub Pages

1. Subir los archivos a tu repositorio de GitHub en la rama `main`.
2. Ir a **Settings** -> **Pages**.
3. En **Build and deployment** seleccionar: `Deploy from a branch` -> Branch `main` / `(root)`.
4. ¡Listo! Tu web estará online en segundos en `https://<tu-usuario>.github.io/<tu-repo>/`.
